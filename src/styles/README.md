# src/styles/

Global CSS stilleri ve TailwindCSS yapılandırması.

## Dosyalar

- `globals.css` — TailwindCSS direktifleri, CSS değişkenleri ve global stiller

## Kurallar

- Bileşen özel stilleri TailwindCSS class'ları ile tanımlanır.
- Global stiller yalnızca CSS değişkenleri ve reset stilleri için kullanılır.
- Tema renkleri CSS değişkenleri üzerinden yönetilir (dark mode desteği).
